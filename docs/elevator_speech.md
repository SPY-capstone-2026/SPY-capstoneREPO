# Elevator Speech — Moni

---

## 문제 (20초)

예산을 세우는데 매달 초과하는 사람들이 있다.
"카페를 너무 자주 간다"는 사실은 알고 있다. 그래도 행동이 바뀌지 않는다.

기존 가계부 앱은 쓴 돈을 기록하고 월말에 통계를 보여준다.
문제는 소비 습관이 월간 통계가 아니라 **오늘의 행동**으로 결정된다는 것이다.
기존 앱은 기록 도구일 뿐, 행동 변화 도구가 아니다.

---

## 해결 아이디어 (20초)

소비가 일어난 후 보여주는 게 아니라, **쓰기 전에 개입**한다.

과거 소비 패턴을 AI가 분석해 이번 달 지출을 예측하고,
예측 결과를 바탕으로 오늘 바로 실천할 수 있는 챌린지를 제안한다.
챌린지를 달성하면 캐릭터가 성장한다.

---

## 기술 / 구현 (30초)

**핵심 파이프라인: 예측 → 압박도 계산 → 챌린지 생성**

```
과거 소비 데이터 (일별 지출)
    ↓
Prophet 시계열 모델로 향후 소비 예측
    ↓
예측 총액 ÷ 월 예산 = budget_pressure (예산 압박도)
    ↓
압박도 + 최근 소비 행동 (어제 지출, 무지출 streak 등)
    ↓
챌린지 난이도 결정 (Easy / Medium / Hard)
    ↓
오늘의 챌린지 + XP 보상 생성
```

**사용 기술**

| 영역 | 기술 |
|------|------|
| 예측 모델 | Python, Prophet |
| 챌린지 생성 | Rule-based (향후 LLM 연동 예정) |
| 백엔드 | FastAPI |
| 프론트엔드 | React |
| DB | MySQL |

Prophet을 선택한 이유: 신규 유저의 2~3개월 데이터처럼 적은 데이터에서도 안정적으로 동작하고, 주말 고지출 같은 주간 계절성을 자동으로 학습한다.

## MVP / 배포 (20초)

**현재 구현된 범위**

- 합성 소비 데이터 생성 (4가지 소비 프로필 지원)
- Prophet 기반 소비 예측 + MAE / RMSE / MAPE 평가
- 예산 압박도 기반 챌린지 난이도 결정
- 챌린지 타입 분기 (금지형 / 제한형 / streak 유지형 / 유지형)
- Colab에서 전체 파이프라인 재현 가능

**실행 방법**

`ai/moni_pipeline.ipynb`를 Google Colab에서 열고 상단 설정값(PROFILE, SEED)을 선택한 뒤 전체 셀 실행.

```python
PROFILE = "balanced"   # "careful" / "balanced" / "overspend" / "custom"
SEED = 42              # None: 매번 다른 결과 / 정수: 재현 가능
```

**향후 확장**

- 카테고리별 예측 모델 분리
- Prophet / ARIMA / LSTM 비교 실험
- 주간 리포트 + 캐릭터 성장 시스템 연동
- 앱 프론트엔드 연결

## PMF (Product-Market Fit)

**타깃**

예산은 세우지만 매달 초과하는 대학생 및 사회초년생.
소비 문제를 인지하고 있으나 구체적인 실천 방법을 모르는 사람.

**Pain Point 근거**

- 기존 가계부 앱의 월 평균 30일 내 이탈율이 높음 — 기록 피로도가 주요 원인
- "카드값이 왜 이렇게 나왔지"는 알아도 "오늘 뭘 참아야 하지"는 모름
- 소비 습관 개선 앱 시장에서 사전 개입형 서비스는 부재

**가설 검증 방향**

- 소규모 사용자 설문 (주변 5~10인) — 챌린지 형태의 동기부여가 실제 행동 변화로 이어지는지 확인 예정
- 게이미피케이션 효과 관련 선행 연구 참고 (Self-Determination Theory, Duolingo 사례)
