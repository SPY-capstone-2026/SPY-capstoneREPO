# AI 소비 예측 모델 비교 리포트

## 1. 배경 및 목적

Moni는 개인의 카테고리별 소비 기록을 이용해 월말 지출을 예측하고, 예산 상황에 맞는 챌린지를 생성합니다. 예측의 안정성과 목표 산정의 정합성을 확인하기 위해 모델을 비교했습니다.

이 문서의 기존 실험은 Prophet·ARIMA·LSTM을 비교하고 당시 LSTM을 선택한 기록입니다. 이후 최신 `main`의 실행 경로는 ARIMA로 전환되었습니다. **과거 실험의 순위와 현재 배포 대상으로 선택한 모델은 별개의 사실**입니다.

---

## 2. 비교 대상 모델

| 모델 | 특징 |
|---|---|
| **Prophet** | 추세·계절성을 분해하는 시계열 모델 |
| **ARIMA** | 자기회귀·차분·이동평균에 기반한 통계 시계열 모델 |
| **LSTM** | 순환 신경망을 이용하는 시계열 모델 |

현재 서버는 `statsmodels.tsa.arima.model.ARIMA`를 호출합니다. 이전 LSTM·Prophet 함수는 실행되지 않는 코드 블록으로 남아 있습니다.

---

## 3. 실험 방법

원 실험은 더미 데이터와 실사용 소비 데이터에서 후보 모델을 백테스트로 비교한 기록입니다. 아래에는 기존 문서의 MAE·순위·일부 실행 속도를 유지했습니다.

이번 갱신에서 원 데이터·실행 로그·학습/평가 분할을 재검증하지 않았으므로, 확인하지 않은 실험 기간·표본 수·RMSE·새 측정값을 보충하지 않습니다. 자세한 과거 실험 조건은 기준 커밋의 원문과 원 실험 자산을 함께 확인해야 합니다.

---

## 4. 실험 결과

### 4-1. 더미 데이터

| 모델 | MAE | 순위 | 속도 |
|---|---|---|---|
| **Prophet** | 19,163 | 1위 | 빠름 (~0.1초) |
| LSTM | 20,932 | 2위 | 느림 (~6초) |
| ARIMA | 23,374 | 3위 | 보통 |

기존 결과에서는 Prophet의 MAE가 가장 낮았습니다. 속도는 해당 실험 기록이며 현재 환경에서 측정한 성능 보장이 아닙니다.

### 4-2. 실사용 데이터

| 모델 | MAE | 순위 |
|---|---|---|
| **LSTM** | 31,684 | 1위 |
| ARIMA | 33,028 | 2위 |
| Prophet | 51,407 | 3위 |

기존 결과에서는 LSTM의 MAE가 가장 낮고 ARIMA가 그다음입니다. **ARIMA로 전환했다는 이유로 기존 순위나 수치를 바꾸지 않습니다.**

---

## 5. 결과 분석

### 왜 더미와 실데이터에서 순위가 반대인가

기존 문서는 규칙적인 합성 데이터와 불규칙한 실제 소비의 차이를 주요 해석으로 제시했습니다. 이를 모든 사용자에게 일반화하려면 더 많은 표본과 동일 조건의 재현 실험이 필요합니다.

### Prophet이 실데이터에서 부진한 원인

기존 문서는 불규칙한 소비와 과대예측 가능성을 주요 해석으로 제시했습니다. 개별 카테고리의 원시 예측값과 오류 분포를 다시 확인하지 않았으므로, 이번 갱신에서 원인을 확정하거나 새로운 구체 사례를 추가하지 않습니다.

### LSTM을 선정한 근거

이 절은 **당시 선택의 근거**입니다. 두 데이터 실험에서 상대적으로 낮은 오차를 보였고 극단적 예측에 대한 우려를 줄이려 했습니다. 다만 현재 모델 선택은 아래 ARIMA 구현 상태로 갱신되었으며, 위 표만으로 ARIMA의 전반적 정확도 우위를 주장할 수 없습니다.

---

## 6. 결론

**현재 코드에는 ARIMA가 적용되어 있습니다.** 메인 실행 분기에서 `_predict_with_arima()`를 호출하고, 서버 의존성에는 statsmodels가 포함됩니다.

ARIMA는 일반적인 신경망 학습 대신 시계열 적합을 수행하며, 현재 구현은 적합 실패와 비정상 과대예측을 평균 예측으로 대체하는 경로를 둡니다. 실제 속도·정확도·운영 자원 개선의 정도는 최신 버전으로 다시 측정해야 합니다.

### 적용 방식

| 항목 | 실제 코드 기준 |
|---|---|
| 모델 | ARIMA(7,0,1) |
| 적합 실패 시 | ARIMA(1,0,0) 재시도, 재실패 시 평균 대체 |
| 현재 외부 진입 | 관측 90일 이상 AND (비영 지출일 비율 ≥0.2 OR 원본 거래 ≥50건) AND 잔여일수 >0 |
| 함수 내부 방어 | 관측 40개 미만이면 평균 대체; 외부 기준과 별개 |
| 평균 대체 | 최근 최대 30일 평균 × 예측 기간 |
| 음수 보정 | 일별 예측을 0 이상으로 보정 |
| 과대예측 가드 | 최근 평균 × 기간 ×20 초과 또는 비유한 합계이면 평균 대체 |
| 구간 | 일별 80% 구간을 이용해 날짜별 오차 독립을 가정한 합산 근사 |
| 목표 연결 | 예상 지출·압박도·남은 예산으로 하루 한도 계산 |

일부 상수명은 아직 LSTM 기준이며, ARIMA 함수 안에서 평균으로 대체해도 외부 `model_used`가 arima로 남을 수 있습니다. 이 상태까지 반영해 검증 결과를 해석해야 합니다.

---

## 7. 한계 및 향후 과제

- 현재 ARIMA와 평균 기준선을 같은 사용자·기간·분할 조건으로 재평가합니다.
- 학습 기간·거래 빈도·카테고리별 표본 수와 원시 결과를 남깁니다.
- MAE·RMSE뿐 아니라 과대/과소예측, 목표 강도, 실행 시간과 실패율을 함께 측정합니다.
- 합산 예측구간의 실제 포함률을 검증합니다. 현재 근사 구간을 정확한 총액 80% 신뢰 보장으로 표현하지 않습니다.
- 관측 90일 진입 조건과 내부 40일 방어 조건의 타당성을 재검토합니다.
- `model_used`가 실제 실행 모델을 나타내도록 코드 명세를 정리합니다.
- 기존 결과는 과거 실험으로 보존하고 새로운 실험 결과는 별도의 날짜·커밋·환경과 함께 추가합니다.
