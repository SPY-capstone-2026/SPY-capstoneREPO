# AI 소비 예측 모델 비교 리포트

> Moni의 소비 예측 엔진에 사용할 시계열 모델을 선정하기 위해, 세 가지 후보 모델(Prophet / ARIMA / LSTM)을 백테스트로 비교한 결과를 정리한 문서입니다.

---

## 1. 배경 및 목적

Moni는 사용자의 과거 소비 내역을 학습해 **카테고리별 월말 예상 지출을 예측**하고, 이를 기반으로 데일리 챌린지를 생성합니다. 예측 정확도가 챌린지의 난이도·한도 산정에 직접 영향을 주므로, 소비 데이터에 가장 적합한 예측 모델을 선정할 필요가 있었습니다.

기존 MVP는 **Prophet**을 사용했으나, 실제 소비 데이터의 특성에 맞는지 재검증하기 위해 대표적인 시계열 예측 모델 세 가지를 비교했습니다.

---

## 2. 비교 대상 모델

| 모델 | 특징 |
|---|---|
| **Prophet** | Meta의 시계열 라이브러리. 추세·계절성 자동 분해. 적은 데이터에서 안정적이라 알려짐 |
| **ARIMA** | 전통적 통계 기반 시계열 모델. 자기회귀·이동평균 결합 |
| **LSTM** | 순환 신경망 기반 딥러닝 모델. 복잡한 시계열 패턴 학습에 강점 |

---

## 3. 실험 방법

- **방식**: 백테스트 (과거 시점에서 예측 후 실제값과 비교)
- **절차**: 매월 15일 시점을 기준으로 월말까지의 지출을 예측하고, 실제 월말 지출과 비교
- **평가 지표**: MAE(평균 절대 오차), RMSE(제곱근 평균 제곱 오차), 예측 속도
- **데이터**: 두 종류로 나누어 검증
  - **더미 데이터**: 직장인 소비 페르소나 기반 합성 데이터
  - **실사용 데이터**: 실제 개인의 약 1년치(2025.07~2026.07) 카테고리별 소비 내역

---

## 4. 실험 결과

### 4-1. 더미 데이터

| 모델 | MAE | 순위 | 속도 |
|---|---|---|---|
| **Prophet** | 19,163 | 1위 | 빠름 (~0.1초) |
| LSTM | 20,932 | 2위 | 느림 (~6초) |
| ARIMA | 23,374 | 3위 | 보통 |

더미 데이터에서는 Prophet이 가장 낮은 오차를 보였습니다.

### 4-2. 실사용 데이터

| 모델 | MAE | 순위 |
|---|---|---|
| **LSTM** | 31,684 | 1위 |
| ARIMA | 33,028 | 2위 |
| Prophet | 51,407 | 3위 |

실사용 데이터에서는 순위가 뒤바뀌어, **Prophet이 가장 나쁜 성능**을 보였고 LSTM이 가장 안정적이었습니다.

---

## 5. 결과 분석

### 왜 더미와 실데이터에서 순위가 반대인가

더미 데이터는 규칙적인 패턴(뚜렷한 주간 계절성, 안정적 추세)으로 생성되어, 추세·계절성 분해에 강한 **Prophet에게 유리한 조건**이었습니다. 반면 실제 소비는 그만큼 규칙적이지 않습니다.

### Prophet이 실데이터에서 부진한 원인

실사용 데이터 분석 결과, Prophet의 큰 오차는 **불규칙한 소비 카테고리에서의 과대예측**에서 비롯됐습니다.

- 정기 구독처럼 규칙적인 지출이 없는 카테고리(예: 문화·여가)에서, Prophet이 추세를 과도하게 외삽하는 문제가 발생
- 실제 월 5천 원 수준의 소비를 24만 원대로 예측하는 등, 소수 카테고리의 과대예측이 전체 오차를 크게 끌어올림
- 반면 식비·편의점처럼 규칙적인 카테고리에서는 ARIMA가 근소하게 우세했으나, 전체적으로는 큰 차이가 아니었음

### LSTM을 선정한 근거

- **두 실험 모두에서 최하위를 기록하지 않음** (실데이터 1위, 더미 데이터 근소한 2위)
- 불규칙 카테고리에서 Prophet과 같은 극단적 과대예측이 없어, 실사용 환경에서 안정적
- Prophet의 유일한 강점은 속도였으나, 예측은 하루 1회 배치 또는 앱 실행 시점에 수행되므로 수 초의 지연은 서비스에 부담이 되지 않음

---

## 6. 결론

**LSTM을 소비 예측 모델로 채택합니다.**

Moni가 다루는 것은 더미가 아닌 실제 개인 소비 데이터이며, 실사용 데이터에서 LSTM이 가장 안정적인 성능을 보였습니다. 특히 불규칙한 소비 패턴에서 극단적 예측 오류가 없다는 점이 챌린지 한도 산정의 신뢰성 측면에서 중요하게 작용했습니다.

### 적용 방식

- 예측 시점마다 개인 소비 데이터로 새로 학습 (개인 소비는 매일 변하므로 최신 데이터 반영)
- 데이터가 충분하고 소비 빈도 조건을 만족하는 카테고리에만 LSTM 적용
- 데이터가 부족하거나 소비 빈도가 낮은 카테고리는 단순 평균 예측으로 자동 분기 (과적합 방지)

---

## 7. 한계 및 향후 과제

- 실사용 데이터의 표본이 제한적이므로, 베타 사용자 데이터로 예측 정확도를 지속 검증할 예정
- 데이터 양에 따른 모델 성능 변화(3개월 / 6개월 / 12개월치)를 추가 실험해, LSTM 적용 기준값(데이터 양·소비 빈도)을 정교화할 계획
