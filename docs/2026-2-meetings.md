### 기능 관련 논의

#### 거래 내역 삭제
- 모바일과 웹의 키 입력 및 동작 방식 차이로 모바일에서는 삭제되지만 Vercel 웹 환경에서는 삭제되지 않는 문제 확인.
- 시연 및 현재 개발 환경이 웹 중심이므로 웹에서 정상 동작하도록 수정하기로 함.

#### 소셜 기능
- 현재 친구의 방을 확인하는 기능만으로는 상호작용이 부족하다는 의견.
- 검증형 챌린지 구조상 친구와 동일한 챌린지를 함께 수행하는 기능은 구현이 복잡함.
- 친구 간 **챌린지 달성 개수를 기준으로 랭킹 및 정렬 기능**을 추가하는 방향으로 결정.
- 소셜 기능은 해당 수준까지 구현하고 지나치게 복잡하게 확장하지 않기로 함.

#### 챌린지 검증
- 사용자가 소비 내역을 입력하지 않아 자동으로 챌린지가 성공 처리될 가능성에 대해 논의.
- **사용자가 완료 체크를 해야만 해당 챌린지가 검증 단계로 넘어가도록 구현**하기로 함.

#### 사용자 닉네임
- 소셜 기능에서 이메일만 표시되는 문제를 개선하기 위해 닉네임 기능 추가.
- BE: 회원가입 및 사용자 정보 수정 시 닉네임을 입력·수정할 수 있도록 구현.
- FE: 사용자 정보 및 소셜 화면에 닉네임을 사용할 수 있도록 수정.

### 우선 개발 사항
- FE는 **CSV 거래내역 업로드 기능을 최우선으로 구현**.
- 웹 환경의 거래내역 삭제 기능 수정.
- 챌린지 완료 체크 기반 검증 흐름 반영.
- 닉네임 관련 FE/BE 연동.
- 소셜 챌린지 달성 개수 랭킹 기능 추가.
